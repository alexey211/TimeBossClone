# ⏱️ TimeBossClone

**Родительский контроль экранного времени для Windows**

Приложение считает время за компьютером, ограничивает его дневным лимитом и блокирует рабочую станцию, когда лимит исчерпан. Идея и название взяты у программы TimeBoss, а реализация написана с нуля на C# / .NET 8 (WinForms).

Проект учебный и домашний. Я писал его, чтобы разобраться с системным программированием под Windows (реестр, учётные записи, блокировка сессии, автозапуск) и с практической криптографией.

## ✨ Возможности

- **Дневные лимиты** отдельно для будних и выходных дней (по умолчанию 120 и 240 минут).
- **Точный учёт времени.** Считается фактически прошедшее время, а не число тиков таймера, с защитой от скачков после сна. Пока сессия заблокирована или переключена на другого пользователя, время не тратится.
- **Блокировка при исчерпании лимита** через `LockWorkStation`. Дополнительно можно блокировать Диспетчер задач и Редактор реестра через политики HKCU.
- **Предупреждения** голосом за 10 и 5 минут до конца (`System.Speech`) и оверлей с таймером поверх окон.
- **Панель родителя** с четырьмя вкладками: статистика и лимиты, учётные записи, безопасность, добавление времени другому пользователю.
- **Работа в трее**, один экземпляр приложения (mutex), автозапуск через реестр.
- **Защита паролем:** PBKDF2-SHA256 (200 000 итераций, соль), пауза после трёх неверных попыток.
- **Многопользовательский сценарий.** Родитель из своей учётки начисляет время ребёнку, запросы подписываются ECDSA P-256.
- **Устойчивость к сбоям.** Конфиг и статистика пишутся атомарно (временный файл, переименование, `.bak`). Ошибки попадают в лог `%APPDATA%\TimeBossClone\timeboss.log`.

## 🛠 Технологии

| Область | Что использовано |
|---|---|
| Язык и платформа | C#, .NET 8 (`net8.0-windows`), Windows Forms |
| Хранение данных | JSON-файлы в `%APPDATA%` |
| Криптография | PBKDF2-SHA256, ECDSA P-256 (`System.Security.Cryptography`) |
| Windows API | `LockWorkStation` (P/Invoke), реестр (`Run`, `Policies`, `ProfileList`), `SystemEvents` |
| Прочее | `System.Speech` (NuGet) |

## 🏗 Архитектура

```text
TimeBossClone/
├── Program.cs                  # точка входа: mutex, первый запуск, обработка исключений
├── Forms/
│   ├── TrayApplicationContext  # иконка в трее, реакция на события, принудительная блокировка
│   ├── AdminForm               # панель родителя (4 вкладки)
│   ├── LoginForm               # вход и первичная настройка пароля
│   └── TimerOverlayForm        # оверлей с оставшимся временем
├── Services/
│   ├── TimeTracker             # учёт времени, состояние блокировки вычисляется
│   ├── ConfigManager           # конфиг и статистика по дням
│   ├── JsonFileStore           # атомарная запись JSON + резервная копия
│   ├── PasswordHasher          # PBKDF2, миграция со старого SHA256
│   ├── RequestSigner           # ECDSA-подпись запросов
│   ├── RequestService          # обмен запросами и ответами (.req / .ack)
│   ├── SystemPolicyService     # политики реестра, список локальных учёток
│   ├── LockService             # блокировка рабочей станции
│   ├── AutostartService        # автозапуск
│   ├── SpeechService           # голосовые предупреждения
│   └── AppLog                  # лог ошибок
└── Models/                     # AppConfig, UsageRecord
```

**Ключевое решение.** `TimeTracker` отвечает только за учёт времени. Состояние «заблокировано» вычисляется из текущих данных (контролируемая учётка, нет флага «разблокировано на сегодня», использовано не меньше лимита), а не хранится флагом. Поэтому добавление минут, смена лимита, смена дня и снятие контроля с учётки сами приводят состояние в порядок. UI и принудительная блокировка вынесены в `TrayApplicationContext`.

## 🔐 Запросы «добавить время»

Родитель отправляет запрос из своей учётки, а получатель применяет его только при корректной подписи:

1. Пара ключей ECDSA P-256 детерминированно выводится из пароля родителя.
2. В конфиге каждой учётки хранится только публичный ключ: подпись можно проверить, но нельзя подделать.
3. В подписанный запрос входят дата, имя получателя и уникальный Id, поэтому запрос нельзя повторить или переадресовать.
4. Получатель проверяет подпись, применяет запрос, запоминает Id и отвечает файлом `.ack` с результатом или причиной отказа.

## 🚀 Сборка и запуск

**Требования:** Windows 10/11 и [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```bash
git clone https://github.com/alexey211/TimeBossClone.git
cd TimeBossClone/TimeBossClone
dotnet run
```

Либо откройте `TimeBossClone.sln` в Visual Studio 2022 и запустите проект. При первом запуске появится окно создания родительского пароля. Дальше приложение работает в трее, а настройки открываются через пункт «Настройки (родитель)».

## ⚠️ Известные ограничения

Приложение работает с правами обычного пользователя, а настройки лежат в его `%APPDATA%`. Технически подкованный пользователь может удалить конфиг, убрать автозапуск из `HKCU\...\Run` или завершить процесс. Надёжная защита требует Windows-службы под SYSTEM и учётной записи без прав администратора. Это отдельный, более крупный проект.
